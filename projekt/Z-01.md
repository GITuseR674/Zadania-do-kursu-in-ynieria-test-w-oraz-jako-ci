# Moduł 1 - Zajęcia Początkowe

## Cel modułu
Skonfigurowanie środowiska pracy: konto GitHub, sklonowanie repozytorium kursowego.

## Materiały
- [GitHub Docs - Getting started](https://docs.github.com/en/get-started)
- [Wprowadzenie do Git](https://docs.github.com/en/get-started/getting-started-with-git/set-up-git)
- [Używanie GitHub Desktop](https://docs.github.com/en/desktop/overview/about-github-desktop)
- [Używanie Git](https://docs.github.com/en/get-started/getting-started-with-git/set-up-git)

## Zadania
1. Stwórz konto na GitHub
2. Kliknij w link do GitHub Classroom wysłany przez prowadzącego
3. Utwórz w dokumentach folder z numerem indeksu (`Documents/<nr-indeksu>`)
4. Otwórz terminal, przejdź do tego folderu i uruchom:
   ```
   git clone <HTTPS URL tego repozytorium>
   ```
5. Ukończ obowiązkowe ćwiczenia GitHub Skills:
   - [Introduction to GitHub](https://github.com/skills/introduction-to-github)
   - [Communicate using Markdown](https://github.com/skills/communicate-using-markdown)
   - [GitHub Pages](https://github.com/skills/github-pages)
   - [Introduction to Git](https://github.com/skills/introduction-to-git)
   - [Code with Codespaces](https://github.com/skills/code-with-codespaces)
   - [Getting started with GitHub Copilot](https://github.com/skills/getting-started-with-github-copilot)

## Wymagania
- [ ] Ukończone wszystkie ćwiczenia GitHub Skills

> [!WARNING]
> **Wyczyść Menedżer Poświadczeń Windows po zajęciach!**
> Panel Sterowania → Menedżer Poświadczeń → Poświadczenia Windows → usuń konto GitHub.
> Jeżeli nie możesz sklonować repozytorium, najpierw wyczyść menedżer poświadczeń.
