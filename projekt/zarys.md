# Zarys kursu

Poniżej znajduje się ogólny przegląd tematów, narzędzi i zasobów wykorzystywanych w ramach zajęć laboratoryjnych.

## Narzędzia
- VS Code + venv (środowisko Python)
- GitHub / GitHub Classroom

## Moduły
1. GitHub i podstawy Git
2. Praca z danymi (Pandas, Matplotlib, Markdown)
3. Podstawy GUI w Tkinter
4. Akwizycja danych (NI DAQmx)
5. Pełna aplikacja (import, export, wyświetlanie, pass/fail)
